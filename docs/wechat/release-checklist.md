# 微信小程序发布检查表

## 导入前

- 微信公众平台已填写名称、头像、简介和实际服务类目。
- `miniprogram/config.ts` 已替换为自有 HTTPS API 域名。
- 该域名已在“开发管理 - 开发设置 - 服务器域名”中加入 `request` 合法域名。
- 后端服务已部署最新代码，`GET /api/health` 返回 `ok: true`。
- 后端环境变量已配置有效的 `OPENAI_API_KEY`，密钥未写入小程序代码。

## 开发者工具

1. 解压 `release/pregnancy-assistant-miniprogram-source.zip`。
2. 在微信开发者工具点击“导入”，选择解压后的 `miniprogram` 文件夹。
3. 填写个人主体小程序的 AppID。
4. 本项目无小程序 npm 依赖，不需要“构建 npm”。
5. 点击“编译”，检查首页、资料、日程和记录页面。
6. 开发阶段可临时关闭合法域名校验；真机预览和正式上传前必须重新开启。

## 真机验收

- 首次进入必须先接受隐私说明并填写孕期资料。
- 孕周、预产期和下一次产检内容可正常显示。
- 日程可新增、编辑、删除和勾选完成。
- 个人记录可添加文字和照片。
- 照片发送前显示单独确认；取消后不得上传。
- OCR 结果可编辑，且无正常/异常、风险、诊断或建议内容。
- 断网或 API 失败时显示技术错误，不生成演示结果。
- 清除数据后资料、日程和记录不可见。

## 上传与审核

1. 开发者工具点击右上角“上传”，版本号建议从 `0.1.0` 开始。
2. 微信公众平台进入“管理 - 版本管理”，找到开发版本。
3. 填写功能页面和审核说明，提交审核。
4. 审核通过后，管理员仍需点击“发布”。
