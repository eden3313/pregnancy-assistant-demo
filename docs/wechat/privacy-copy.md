# 用户隐私保护指引填写参考

小程序用于用户自主记录孕期资料、日程、文字和照片。孕期资料、日程及确认后的记录默认保存在用户当前设备。

用户主动使用“报告文字整理”时，所选照片会发送至小程序服务端及模型服务，仅用于提取可见文字、生成原文摘要和解释通用术语。服务不提供诊断、风险判断、正常异常判断、医学建议或药物建议，服务端不长期保存原图。

用户可以在“我的资料”中清除本地资料、日程和记录。

v1.1.0新增药品图片文字识别：所选药盒、说明书或已有处方图片在逐次确认后发送至本程序HTTPS后端及OpenAI，仅转录原文药名和原文服用时间要求。结果由用户核对后转换为固定时间日程，不根据药名推断用法、剂量或适用性。默认配置涉及境外服务，必须按实际运营安排补充接收方、联系方式、权利行使方式及适用的出境处理要求，不能仅填写“全部数据不出本机”。

后端不将图片写入磁盘，API使用store:false；不代表服务商零保留。运营主体、联系邮箱、具体后端域名和服务商处理政策须按真实情况补齐。取消上传不调用API，用户可不使用图片识别功能而手动录入。

> 提交前应根据微信后台实际隐私接口清单核对并补充，不要直接把本文件当作法律意见。
