# 每日用药日程与宝宝大小类比设计

## 目标

在优先通过个人主体小程序审核的前提下，完成三项改动：隐藏报告照片的在线解析；在孕期状态页增加宝宝大小的趣味类比；让用户自行填写药物名称、准确时间和饭前/随餐/饭后/固定时间，并每天自动生成可勾选完成的日程。

## 产品边界

- 小程序只记录用户原始输入，不根据药名推断服法、剂量、相互作用或风险。
- “饭前/随餐/饭后/固定时间”只是用户自己选择的标签；日程时间完全采用用户填写的准确时间。
- 宝宝大小是按孕周给出的趣味类比，不作为医学测量或发育判断。
- 照片只作为本机记录附件，不上传服务器，不显示在线解析入口、解析进度、术语释义或联网处理说明。报告解析实现保留在仓库的上传目录之外，待 HTTPS 后端就绪后再恢复。

## 已选方案与备选方案

### 用药日程

1. 只在保存资料时生成当天日程：实现简单，但第二天不会自动出现。
2. 每日按需生成：每次打开“今日”或“日程”时，为当天补齐三餐和用药提醒，并用稳定编号避免重复。**采用此方案**，因为持续可用且不会提前制造大量未来记录。
3. 一次生成未来 7～30 天：便于预览，但修改用药信息时同步困难且本地数据膨胀，不采用。

### 报告功能

1. 仅隐藏按钮但保留 API 代码：改动最少，但审核包仍包含不可用的联网实现。
2. 从正式小程序上传目录移除在线解析入口、调用与占位 API 配置，保留本地照片和文字记录；可恢复实现留在仓库的 `future-features` 目录及 Git 历史中。**采用此方案**，因为审核边界清晰且后续仍可恢复。

### 宝宝大小

1. 引入每周图片素材：视觉更丰富，但增加包体和素材维护成本。
2. 使用文字卡片和 CSS 视觉强调显示孕周类比。**采用此方案**，保持包体轻且避免引入新素材。

## 数据设计

新增 `MedicationPlan`：

- `id`: 本机稳定编号。
- `name`: 用户输入的药物名称。
- `time`: 用户输入的 24 小时时间，格式 `HH:mm`。
- `relation`: `beforeMeal | withMeal | afterMeal | fixedTime`。

`PersonalProfile.medications` 从自由文本改为 `MedicationPlan[]`。旧版字符串数据加载时迁移为可编辑、可清空的 `legacyMedicationNotes`，避免旧记录丢失；旧记录不自动生成日程，因为没有准确时间。

`ScheduleType` 新增 `medication`。自动生成的用药日程带 `sourceMedicationId`，编号为 `medication-{计划编号}-{日期}`。同一天重复打开页面不会产生重复项。

本地状态升级为版本 2。加载版本 1 时保留资料、日程、记录和隐私同意时间，并迁移旧用药文本。

## 页面与交互

### 初始资料与“我的资料”

- 用药区支持添加、修改和删除多条用药计划。
- 每条包含药物名称输入框、准确时间选择器和服用关系选择器。
- 页面显示说明：“请按药品说明书或医生已给出的要求填写；本工具仅记录和提醒。”
- 至少允许零条用药计划；不完整的行不能保存。
- 旧版自由文本存在时，以“旧版用药原文记录”展示，可编辑或清空，但不会生成提醒。

### 每日生成

- 打开“今日”或“日程”时，调用同一领域函数同步当天自动日程。
- 自动补齐当天早餐、午餐、晚餐和所有有效用药计划。
- 已存在的同编号项目不重复生成。当天未完成的提醒随计划名称、时间或关系变化而同步更新。
- 如果当天提醒已经勾选完成，之后修改计划时该条完成记录保持原样且当天不再生成新提醒；新设置从第二天生效。
- 删除用药计划后，尚未完成的当天自动日程随资料保存同步移除；已完成记录继续显示为当天历史。
- 自动用药日程可勾选完成，但不能在日程页直接改名或删除；需回“资料”修改来源计划。
- 用户手工创建的日程保持原有编辑、删除和完成能力。

### 宝宝大小类比

- `PregnancyOverview` 增加 `babySizeComparison`，按孕周区间返回简短类比文案。
- “宝宝状态”卡片显示“趣味大小类比：约……”，下方固定提示“仅作直观参考，个体差异较大，以产检结果为准。”
- 不展示推算体重、身长或正常/异常判断。

### 个人记录

- 保留选择照片、文字正文、标题、日期和标签。
- 移除“整理报告文字”按钮、联网确认弹窗、解析状态和术语释义卡片。
- 隐私说明改为照片和资料默认仅保存在当前设备，不再描述向服务端或模型服务发送照片。

## 错误处理

- 药物名称为空、时间格式无效或服用关系无效时阻止保存并给出明确提示。
- 本地旧状态损坏时沿用现有安全回退；合法版本 1 状态执行迁移。
- 自动生成函数必须幂等，同一天调用多次结果一致。
- 自动生成或迁移不得覆盖用户手工日程、已完成状态和个人记录。

## 验证范围

- 领域测试：资料校验、宝宝大小区间、状态迁移、每日生成幂等、计划更新和删除、完成状态保留。
- 页面类型检查：初始资料、我的资料、今日、日程和记录编辑页。
- 静态检查：小程序上传包中不再引用报告 API、占位 API 域名或在线解析文案；可恢复代码只存在于上传目录之外。
- 回归：现有前端测试、服务端测试、网页构建和小程序包体检查继续通过。

## 非目标

- 不提供服药剂量、疗程、漏服处理、药物相互作用或孕期安全性建议。
- 不根据三餐时间自动计算饭前或饭后分钟数。
- 不接入通知订阅、云同步、账号体系或远程数据库。
- 不新增报告 OCR、医学解释或异常判断。
