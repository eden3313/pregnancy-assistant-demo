# 报告在线解析（暂不进入审核包）

该功能在小程序首次审核期间停用。`miniprogram/` 上传目录只保留本地照片附件和手工文字记录，不包含 API 域名、网络请求或在线解析入口。

以后恢复前必须完成：

1. 将 `report-api.ts` 复制回小程序服务目录并改为正式 HTTPS API 域名。
2. 在微信公众平台配置合法 `request` 域名。
3. 在记录编辑页重新接入用户主动确认、解析进度和结果核验流程。
4. 更新用户隐私保护指引，准确说明照片传输目的、接收方和保存期限。
5. 真机验证成功后，以新版本重新提交微信审核。

服务端受限解析接口仍保留在 `server/report-extractor.mjs`，只允许文字提取、原文整理和通用术语释义，不允许诊断、异常判断、风险或用药建议。
